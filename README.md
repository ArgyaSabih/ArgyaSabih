### AI and computer vision

| Project | What it does | Stack |
| --- | --- | --- |
| [**real-time-object-detection-system**](https://github.com/ArgyaSabih/real-time-object-detection-system) | Desktop app that runs YOLO on webcam video across 80 COCO classes with bounding boxes, confidence scores and an FPS panel.
